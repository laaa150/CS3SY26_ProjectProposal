### Project Description:
  A Rogue Edu modification that aims to model itself after the classic video game Pac-Man, a maze game in which the player is constantly chased around by 4 different color (Red, Orange, Blue, Pink) and behavior coded ghosts while having to collect Pac-Dots (small coins) to progress, with power pellets appearing twice per stage, giving Pac-man the ability to eat the ghosts and make them return to their home base. Using Rogue Edu as a base, we can easily modify how the ghosts behave and interact with each other and the player, and it is also easy to modify the walls of the map, changing it per level.
